# 555-synth


Single-note synthesizer using NE555 and Digital Fabrication tools

Conponents:
- NE555
- 10nF Capacitor (C1)
- 2x 100nF Capactorot (C2)
- 10k Resistor (R1)
- 1k Resistor (R2)
- 10k Potentiometer (POT1)
- Slider Switch
- Piezo Buzzer
- LED
- 18650
- Push Button
